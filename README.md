# Tiendas D2 - Portal Corporativo (Sede Ipiales)

Plataforma web corporativa y serverless diseñada para la **Sede Ipiales** de **Tiendas D2**, enfocada en la gestión institucional de requerimientos, atención al cliente (PQRS) y postulaciones corporativas (ofertas de empleo con carga de hojas de vida en formato PDF).

---

## 🚀 Características Principales

* **Interfaz de Alta Gama (UI/UX):** Diseño moderno, limpio y corporativo basado en tonos esmeralda y pizarra, con componentes estilizados y experiencia optimizada.
* **Gestión de Solicitudes (PQRS y Empleo):** Formulario dinámico que despliega automáticamente el campo de adjuntar Hoja de Vida (PDF) al seleccionar la categoría correspondiente.
* **Validación Robusta de Archivos:** Control estricto del lado del cliente para aceptar únicamente formatos PDF con un límite máximo de tamaño de **10 MB**, acompañado de notificaciones flotantes dinámicas.
* **Base de Datos Cloud en Tiempo Real:** Conexión directa y segura con **Supabase (PostgreSQL)** mediante arquitectura serverless (sin necesidad de servidores backend como Node.js o Flask).
* **Panel de Administración Integrado:** Vista dual que permite alternar entre el formulario de envío y la tabla ejecutiva en la nube para consultar registros de manera instantánea.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3:** Estructura semántica y estilos avanzados basados en variables CSS (`:root`) con tipografía moderna (*Inter*).
* **JavaScript (ES6+):** Lógica asíncrona para la validación de archivos, interactividad de la interfaz y sincronización con la base de datos.
* **Supabase JavaScript Client (`supabase-js@2`):** Conector oficial para la persistencia e indexación de datos en PostgreSQL.
* **Supabase PostgreSQL:** Base de datos relacional en la nube en tiempo real.

---

## 📋 Estructura de la Base de Datos (Supabase)

Para el correcto funcionamiento del portal, la tabla `solicitudes` en PostgreSQL se encuentra estructurada con los siguientes campos:

```sql
create table solicitudes (
  id bigint generated by default as identity primary key,
  nombre text not null,
  correo text not null,
  telefono text not null,
  tipo_solicitud text not null,
  pdf_nombre text,
  mensaje text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
